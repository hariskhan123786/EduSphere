=====================================================
EduSphere AI - Desktop Installation Package
=====================================================

HOW TO INSTALL ON ANY WINDOWS PC:
---------------------------------
1. Copy this folder or the ZIP file to any Windows computer.
2. Double-click 'Install-EduSphere.bat' (Run as normal user).
3. It will automatically:
   - Install EduSphere AI to AppData
   - Create a Desktop Shortcut ('EduSphere AI')
   - Create a Start Menu item
   - Launch the application automatically!

SYSTEM REQUIREMENTS:
--------------------
- Windows 10 / Windows 11 (64-bit)
- Microsoft Edge WebView2 (included by default on Windows 10 & 11)
- Works completely offline (Local SQLite cache) and syncs when online.
