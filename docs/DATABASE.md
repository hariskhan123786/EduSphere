# EduSphere AI — Database Schema & Data Dictionaries

## Tables (19 Entities)
1. `organizations` — Multi-tenant campus registries
2. `users` — Authentication accounts and credentials
3. `students` — Student demographics, CNIC, roll numbers, guardian contacts
4. `teachers` — Faculty assignments and salary contracts
5. `attendance` — Daily attendance registers
6. `fee_invoices` — Fee vouchers formatted in PKR
7. `expenses` — School operational expenses
8. `payrolls` — Faculty and staff monthly salary records
9. `homework` — Class assignments
10. `homework_submissions` — Graded student submissions
11. `exams` — Examination schedules
12. `results` — Term report marks and letter grades
13. `timetables` — Weekly class and period schedules
14. `leave_requests` — Staff leave applications
15. `notices` — Broadcast notices
16. `school_events` — Campus calendar events
17. `library_books` — Library book catalog
18. `transport_routes` — Bus routes and driver contacts
19. `hostel_rooms` — Boarding rooms and occupancy
