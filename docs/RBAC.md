# EduSphere AI — Role-Based Access Control (RBAC) Matrix

## Defined Roles
1. **Super Admin**: SaaS Platform Owner, multi-campus subscriptions, tenant creation.
2. **School Admin / Principal**: Full operational authority over students, faculty, timetables, and campus policies.
3. **Teacher / Faculty**: Attendance marking, homework assignment, marks matrix grading.
4. **Accountant / CFO**: Fee voucher generation in PKR, expense tracking, payroll execution.
5. **Student**: Report card access, homework submission, fee challan downloads.
6. **Parent**: Child progress radar, attendance inspection, fee payments.
7. **Librarian**: Book catalog circulation.
8. **Transport Manager**: Fleet routes and bus driver tracking.
